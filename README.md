**Voxel-wise Quantitative Susceptibility Mapping (QSM) Analysis Pipeline**
These files are illustrative examples and do not include new data analyses


* **Overview**

The primary goal of this project is to establish a standardized and reproducible processing pipeline for QSM data analysis. Here, you will find:
1. Data Processing Workflow: Step-by-step recommendations for voxel-wise QSM data processing, from raw phase images to susceptibility maps ready for statistical analysis.
2. Toolkit & Commands: A curated list of applicable software toolkits (e.g., QSMexplorer, Ironsmith, QSMxT) along with example command-line instructions to facilitate implementation.
3. GLM Design Examples: Template General Linear Model design files for use in subsequent statistical analyses (e.g., using SPM, FSL). These examples cover common experimental designs to help you structure your own analyses.
